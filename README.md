# 🔥 화재 탈출 넘버원 (2022 개정 교육과정 & 3D 방탈출 안전 교육 시뮬레이터)

초등학교 2022 개정 교육과정 연계 화재 예방·대피·방탈출 시뮬레이션 웹앱(PWA)입니다.

## 📁 파일 구성
- `index.html`: 메인 실행 파일 및 반응형 모달·HUD 레이아웃 (GitHub Pages 진입점)
- `style.css`: 반응형 UI, 다크 글래스모피즘, 고대비·색각 이상 배려 모드 및 인쇄 스타일시트
- `sound.js`: Web Audio API 기반 실시간 효과음·사이렌 및 한국어 음성 안내(TTS) 모듈
- `stages.js`: 스테이지 0~6(예방 점검, 침실, 거실·주방, 4층 아파트, 초등학교 과학실, 지하철역, 종합 방탈출 타워) 및 오늘의 챌린지 시드 생성 모듈
- `editor.js`: 우리 학교 대피도 커스텀 맵 에디터, 도면 사진 트레이싱, URL 공유(`?map=`), BFS(열쇠·소방도끼 포함) 탈출 경로 검증 모듈
- `tactical-3d.js`: 3D 쿼터뷰 디오라마(`DIORAMA_3D`) 및 1인칭 FPS 레이캐스터(`FPS_3D`) 듀얼 3D 전술 뷰 렌더러
- `game.js`: 핵심 물리 엔진, 화재 유형별 소화 시뮬레이션, 방화문 연기 차단, 4대 방탈출 퍼즐(비상 금고, 배전반, 전선 수리, 잠긴 방화문), 교사 스마트보드 모드 및 생기부·인증코드 집계 모듈
- `sw.js` / `manifest.webmanifest` / `ys-install.js` / `ys-qr.js`: 오프라인 PWA 캐시 및 홈 화면 설치·QR 모달 지원

## ✨ 주요 교육 기능
1. **듀얼 3D 전술 시점**: 3D 입체 쿼터뷰(`DIORAMA_3D`)와 1인칭 시점(`FPS_3D`) 실시간 전환(`V`키) 지원
2. **화재 유형별 과학적 진압 & 대피 훈련**: 일반·전기·식용유(K급)·금속(D급) 화재 구분, 손등 문 온도 확인, 젖은 수건·낮은 자세(`C`키), 완강기 탈출, 119 신고 시뮬레이션
3. **교사용 스마트보드 & 학급 운영 도구**:
   - 학급·단계·학년군·시간 정책 프리셋 QR 코드 및 공유 링크 생성
   - 방탈출 커스텀 문제(4자리 금고 암호 및 2지선다 퀴즈) 출제 및 전 스테이지 연동
   - 학생 클리어 인증코드(`119-S1-S1850-42`) 1초 일괄 통계 집계 및 CSV 내보내기
   - 2022 개정 교육과정 성취기준 기반 학교생활기록부(자율·창체·행발) 문구 자동 생성기

## 🚀 GitHub Pages 배포 방법
1. 저장소 루트(Root) 경로에 프로젝트 파일 전체를 업로드합니다.
2. 저장소의 **Settings > Pages > Build and deployment**에서 Branch를 `main`, 폴더를 `/ (root)`로 설정하고 **Save**를 누릅니다.
3. 배포된 주소(`https://<계정명>.github.io/<저장소명>/`)로 접속해 플레이합니다.
